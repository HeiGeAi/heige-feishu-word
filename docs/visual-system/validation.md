## 可复现的本地检查

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
PYTHONPATH=src python3 -m heige_feishu_word gallery --output build/gallery
node scripts/check_browser.cjs build/gallery build/browser-evidence
python3 -m pip wheel . --no-deps --wheel-dir build/dist
```

浏览器脚本需要可选 Playwright 和 Chromium。模块不在默认路径时设置 `PLAYWRIGHT_MODULE`。六份合成 Body 位于 `examples/presets`，README 截图来自离线预览。统计图 SVG 源图如下，云端字形可能由客户端重新排版。

## 验收中实际修复的问题

1. 水墨副标题可能超出墨色背景，改为安全内缩排版。
2. 声浪与两行副标题可能相碰，重设文字区域和波形高度。
3. 窄屏大图最小宽度挡住第一次放大，修复并验证实际尺寸变化与两种关闭方式。
4. 工作流换肤误改正文中的十六进制色值，限制为只改绘图的 fill、stroke 属性。
5. 编译期间出现用户新增文件时，最终写入前复查并拒绝覆盖，保留用户文件。
6. 两处短尾行按中文逗号重新断行，原始正文保持完整。

## 未覆盖的情况

没有实体手机、全部飞书租户、PDF 导出、长期运行或真实业务数据验收。HTML 增强块通过当前账号与 Chrome 样本，不能推断所有客户端都支持。画板导出为 2560×2560 缩略图，图形位于上部、下方有留白；这属于导出画布，不等于文档实际块高度。

图表为输入数据的静态快照，原生表格后续编辑不会自动重绘。6 套模板不意味着任意长度的正文都能塞进固定画板；超出容量会报错，需拆图或调整文案与单位。

原始云端回执、文档标识和浏览器完整证据存于本地私有构建目录，不包含在公开仓库中。
