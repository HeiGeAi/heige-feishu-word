# 白页视觉复审

日期：2026-09-10。触发：使用者认为上一版整体仍不好看，要求把飞书白色文档作为设计场景重新评估。

## 上一版的问题

- 飞书原生标题与画板大标题重复，结论被大幅开篇图推到首屏以下。
- 深色、粉色、米色整块画布与白色文档交替，造成明显拼贴感。
- 统计图内重复章节标题、结论与来源，上下装饰约占原 900px 高度的四成。
- KPI 被用作二级标题，产生 2.1、2.2 等目录编号，混淆内容层级。
- 四步流程使用六步蛇形骨架，留下大块空白；部分字在文档缩放后偏小。
- 离线网页采用独立网站的宽度与主视觉，其漂亮程度无法代表飞书中的连续阅读。

上一版的内容与几何测试仍有价值，但它们不证明整篇文档好看。此前对视觉验收的判断不充分。

## 本轮设计准则

以 HeiGe-Design 的 grid-bureau 白色记录页为共同结构，保留六个来源主题的小面积强调色与排版签名。原设定集中的深色整页、墨团与巨幅声浪不适用于当前宿主场景，因此采用文档适配版本。

1. 白色画布与深色正文统一，浅灰只用于结构分隔。
2. 主标题、章节标题和图表上下文各有一个位置，不再反复画在图里。
3. 颜色表达重点和数据分类，避免满幅底色。
4. KPI、统计图与流程根据内容使用紧凑高度。
5. 文档首先给出结论，然后是读数、证据和行动。

## 对应实现

- 默认正文取消开篇海报，缩短元信息。
- KPI 改为紧凑白底数字条，不再使用标题编号。超过视觉容量的旧输入回退完整原生表。
- 图表数据、指标原始记录和流程说明集中到文末，主线保留来源与业务行动，避免连续阅读被重复内容打断。
- 嵌入图仅保留系列、单位、坐标、标签、精确数值。上下文留在原生文档。
- 独立图通过 standalone 产物保留完整标题、结论和来源，便于单独导出。
- 离线预览使用接近飞书的 820px 白色阅读栏和约 32px 主标题。
- HTML 增强组件仅替换 KPI 图，不再重复文档标题与元信息。

## 验收方式

先创建一份白页项目简报，检查真实文档首屏与滚动效果；确认紧凑白板实际占位后再运行六套。源 SVG 的 viewBox 或方形缩略图都不能证明飞书块的真实高度。最终分别记录内容回读、云端图形、真实浏览器、窄屏模拟与尚未完成的实体设备验证。
